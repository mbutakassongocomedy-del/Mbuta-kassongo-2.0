# Site oficial — Mbuta Kassongo

Use GitHub Pages com:
- Branch: `main`
- Folder: `/docs`

Depois de publicar, coloque a foto oficial em `docs/assets/mbuta-kassongo.jpg` e substitua `SEU-DOMINIO.com` pelo endereço real. Substitua também o e-mail, se adicionar um.

O site inclui SEO básico, canonical, Open Graph, sitemap, robots.txt e dados estruturados ProfilePage + Person + sameAs.
